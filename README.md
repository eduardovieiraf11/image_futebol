# image_futebol

Repositório de imagens para aplicar no FlaNews diariamente, organizado por competição e time para uso nas tarefas agendadas do Claude Cowork.

## Estrutura

- `<Competição>/times/<NomeDoTime>/escudo/` — escudo do clube
- `<Competição>/times/<NomeDoTime>/logo/` — logo do clube
- `<Competição>/times/<NomeDoTime>/jogadores/` — fotos individuais de jogadores do clube
- `banners/` — banners e artes para posts (não específico de competição/time)
- `posts/` — artes finais prontas para publicação (não específico de competição/time)

## Competições

- `Brasileirao Serie A/times/` — Athletico Paranaense, Atlético Mineiro, Bahia, Botafogo, Chapecoense, Corinthians, Coritiba, Cruzeiro, Flamengo, Fluminense, Grêmio, Internacional, Mirassol, Palmeiras, RB Bragantino, Remo, Santos, São Paulo, Vasco, Vitória

Basta adicionar as imagens na subpasta correspondente do time. As tarefas agendadas podem referenciar os arquivos diretamente pelo caminho no repositório.
